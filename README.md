# EduPay Waitlist Admin — Launch Control

Standalone Next.js + TypeScript frontend.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Important
This is a frontend prototype with illustrative demo data only. It is not connected to production waitlist records, authentication, email, or campaign sending. Do not deploy as a production admin tool until backend authorization, CSRF/CORS, and cross-domain authentication have been implemented and tested. Never put owner IDs or private credentials in frontend variables.
